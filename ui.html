🔑 Passo a passo: Como criar seu Personal Access Token (PAT)
  1. Acesse o GitHub e vá até Settings > Developer settings > Personal access tokens > Tokens (classic).
  2. Clique no botão Generate new token e escolha Generate new token (classic).
  3. No campo Note, dê um nome para identificar (ex: Rollback UI).
  4. Defina a validade (Expiration) conforme sua preferência.
  5. Na seção Select scopes, marque obrigatoriamente as seguintes caixinhas:
    • repo (Necessário para acionar o workflow do GitHub Actions).
    • read:packages (Necessário para listar as imagens disponíveis no GHCR).
  6. Role até o final da página e clique em Generate token.
  7. Copie o token gerado (geralmente começa com ghp_). Você não poderá vê-lo novamente após sair da página.

  2. Confirme os dados do repositório, o nome do pacote e clique em Buscar Tags do GHCR.
  3. Selecione a Tag desejada, escolha o ambiente e clique em Acionar Rollback.
